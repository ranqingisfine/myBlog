# 11.1.9 AI私厨实战

## 1、功能实现

### 1.1 需求

- 📸 **图片识别** - 上传食材图片，自动识别其中的食材
- 🔍 **智能搜索** - 根据识别的食材搜索相关食谱
- 🍽️ **智能排序** - 按推荐度、难度、营养价值对食谱进行排序
- 💡 **创意建议** - 当找不到合适食谱时，提供创意搭配建议
- 💬 **对话交互** - 聊天式界面，支持图片上传 + 文本对话

### 1.2 代码

```python
# 1️⃣ 导入依赖
from langchain.agents import create_agent
from langgraph.checkpoint.sqlite import SqliteSaver
from langchain.chat_models import init_chat_model
from langchain_tavily import TavilySearch
from openai import OpenAI
from dotenv import load_dotenv
import sqlite3
import os
# 加载 .env 环境变量（API Key / Base URL）
load_dotenv()

# 2️⃣ 初始化大模型（LLM）
# 这里是“Agent的大脑”
# 使用通义千问（OpenAI兼容接口）
llm = init_chat_model(
    model="qwen3.7-plus",
    model_provider="openai",
    base_url=os.getenv("DASHSCOPE_BASE_URL"),
    api_key=os.getenv("DASHSCOPE_API_KEY"),
)

# 3️⃣ 初始化工具（Tools）
# Tavily：联网搜索工具（用于查菜谱）
tavily = TavilySearch(max_results=5)
# agent 可用的工具列表
tools = [tavily]

# 4️⃣ Vision 模型（图片识别）
# 单独使用 Qwen-VL 做图像理解
# 用来把“冰箱图片 → 食材列表”
client = OpenAI(
    api_key=os.getenv("DASHSCOPE_API_KEY"),
    base_url=os.getenv("DASHSCOPE_BASE_URL")
)

def vision_tool(image_url: str):
    """作用：输入图片URL，输出图片中的食材列表（文本）
    为什么单独拆出来？
    Agent 不稳定处理 image input
    所以用 vision model 先做结构化转换
    """
    resp = client.chat.completions.create(
        model="qwen-vl-max",
        messages=[
            {
                "role": "user",
                "content": [
                    {# 图片输入
                        "type": "image_url",
                        "image_url": {"url": image_url}
                    },
                    {# 文本提示
                        "type": "text",
                        "text": "识别图片中的所有食材，用中文逗号分隔"
                    }
                ]
            }
        ]
    )
    return resp.choices[0].message.content

# 5️⃣ SQLite 记忆系统（Memory）
# 创建本地 SQLite 文件
connection = sqlite3.connect(
    "resources/chef_memory.db",
    check_same_thread=False
)
# LangGraph checkpoint：
# 用来保存 agent 的对话状态（memory）
checkpointer = SqliteSaver(connection)
# 初始化数据库结构
checkpointer.setup()

# 6️⃣ 创建 Agent（核心）
agent = create_agent(
    model=llm,# LLM（大脑）
    tools=tools,# 工具（联网搜索）
    checkpointer=checkpointer # 记忆系统（SQLite）
)

# 7️⃣ 主业务函数（AI厨师）
def ai_chef(image_url: str, user_input: str, session_id: str = "user_1"):

    # -------------------------
    # Step 1：视觉识别
    # -------------------------

    # 把图片转成结构化食材列表
    ingredients = vision_tool(image_url)

    # -------------------------
    # Step 2：构造 Prompt
    # -------------------------
    # 将视觉结果 + 用户需求拼成 agent 输入
    input_msg = f"""
你是一个专业私人厨师Agent。

用户食材：
{ingredients}

用户需求：
{user_input}

要求：
1. 如果需要，可以使用 search 工具
2. 给出3道菜
3. 做法清晰
4. 健康优先
"""

    # -------------------------
    # Step 3：调用 Agent
    # -------------------------
    # thread_id = session_id
    # 👉 这是 memory 的关键
    # 👉 同一个 thread_id 会自动记住上下文
    result = agent.invoke(
        {
            "messages": [
                ("user", input_msg)
            ]
        },
        config={
            "configurable": {
                "thread_id": session_id   # ⭐ memory关键
            }
        }
    )
    # -------------------------
    # Step 4：返回最终结果
    # -------------------------
    # messages[-1] 是最后一次 AI 输出
    return result["messages"][-1].content

# 8️⃣ 测试运行
image_url = "https://img.freepik.com/free-photo/arrangement-different-foods-organized-fridge_23-2149099882.jpg"

result = ai_chef(
    image_url=image_url,
    user_input="根据图片食材给我搭配午餐和晚餐，要求营养均衡",
    session_id="user_002"
)

print("\n🍳 AI私人厨师输出：\n")
print(result)
```

### 🌟 核心主菜（午餐第二道菜）深度解析
## 🍲 鸡肉蘑菇土豆炖（温润滋补·健康少油版）
这道菜是午餐的能量核心。传统的炖菜容易油大或勾芡，我为您改良了**健康烹饪法**，利用食材本身的特性来提鲜和浓稠汤汁，低脂且饱腹感极强。

*   **鸡肉（300g）**：推荐去皮鸡腿肉（口感嫩滑）或鸡胸肉（极致低脂）。切成3cm见方的块。**去腥**：冷水下锅，加两片姜，煮沸后撇去浮沫，捞出温水洗净。

*   **胡萝卜（半根）**：切滚刀块；**洋葱（半个）**：切粗丝。

1.  **洋葱炒糖色（天然增甜）**：锅中喷入少许橄榄油（约5g），中火放入洋葱丝，耐心翻炒至洋葱变软、边缘微焦透明。这一步能释放洋葱的天然甜味，替代传统的炒糖色。
2.  **主料煸炒**：倒入焯好的鸡肉块和胡萝卜块，翻炒2分钟，让鸡肉表面微微收紧。

5.  **自然收汁（健康关键）**：挑出土豆块（防止煮碎），开大火收汁。**不需要勾芡**，利用土豆在炖煮中释放的天然淀粉，汤汁就会变得浓郁粘稠。最后根据口味加少许海盐，将土豆倒回锅中裹匀汤汁即可出锅。

    3. **注意**：临吃前再将酱汁淋在蔬菜上拌匀，保持生菜脆爽。

*   **搭配理由**：炖菜偏温润，这道菜提供丰富的Omega-3脂肪酸，彩椒增加清脆口感和鲜艳色彩，实现“海陆双拼”的营养矩阵。

    4. 翻面，继续煎1-2分钟（推荐5-7分熟，内部呈诱人的粉橙色，口感最嫩）。
    5. 出锅装盘，旁边配上烤好的彩椒块，可挤上少许柠檬汁提鲜。

## 2、LangSmith联调测试

LangChain的Agent底层是基于LangGraph实现的，而LangGraph提供了完整的后端部署功能，自带非常完善的API接口，无需我们额外处理。

同时，LangChain还提供了基于LangSmith的GUI控制台实现Agent的调试、监控、一键部署。

接下来我们就看看如何利用LangGraph在本地部署测试我们的Agent，并通过LangSmith做测试。
