# 11.2.4 总结

1. **MCP是什么**
   1. 开放协议，标准化LLM应用获取工具的方式
   2. 客户端-服务器架构
2. **连接方式**
   1. STDIO: 本地MCP服务器
   2. HTTP: 远程MCP服务器
3. **使用流程**
   1. 配置MultiServerMCPClient
   2. 调用get_tools()获取工具
   3. 创建Agent并调用
4. **自定义MCP Server**
   1. 导入FastMCP
   2. 使用@mcp.tool装饰函数，定义工具（必备）
   3. 使用@mcp.resource装饰函数，返回resources（可选）
   4. 使用@mcp.prompt装饰函数，返回Prompt（可选）
   5. 使用mcp.run()启动MCP服务
